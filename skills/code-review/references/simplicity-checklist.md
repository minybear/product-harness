# 最简实现轴

问：在已批准设计下，这是不是够用的最小改动？

| 信号 | 处理 |
|---|---|
| 新框架、新 UI 库、新设计 token 体系 | Blocker（未批准） |
| 新抽象层/接口/工厂，但只有一个实现且设计未要求 | Major |
| 为未来外部服务商预留大量空实现/策略类，需求只有一家 | Major |
| 把可配置项做成新微服务或新表，设计只要求改现有类 | Major |
| 大范围无关重构、重命名、格式化 | Major |
| 重复 3 行未抽方法 | 通常忽略；过早抽公共库才报 |
| 复制粘贴一小段但保持本地可读 | 允许；不要为 DRY 跨模块抽 |

允许：在当前项目已有扩展点增加满足需求的实现。
