# Java 单测基线（可选）

只在 Java 项目使用本参考。测试框架、JDK、目录和命令以当前项目为准。

1. 阅读构建文件与同模块现有测试，沿用 JUnit 版本、断言库和基类。
2. 纯逻辑测试优先隔离依赖，避免无必要的应用上下文启动。
3. 测试类与生产类包结构保持一致。
4. 不假定项目默认跳过测试，不依赖未提供的内部规范或共享库。

Gradle 示例（替换为本项目的模块和类）：

```text
./gradlew :app:test --tests 'com.example.app.ExampleTest'
```

外部系统、数据库与设备集成使用项目已配置的独立测试环境。
