# 公开整理说明

## 包含

- 通用协作与文档治理规则。
- 15 个通用 Skill 及必要参考模板。
- 空白产品适配模板与项目安装、宿主接入脚本。
- 设计指纹计算工具及其测试。

## 排除

- 真实产品包、专用模块开发 Skill、专用技术规范。
- 公司及客户标识、内部托管地址、员工路径、生产配置与业务工具。
- 历史 Git 数据、工作日志、暂存副本、备份和第三方可选 Skill。

## 通用化调整

通用层在仓库根目录；测试与审查不再要求特定公司规范、语言版本或共享库。
领域调研依据项目证据触发，示例使用普通应用场景。
设计指纹工具仅使用自身 npm 依赖；安装器同时分发工具，避免安装后缺少指纹实现。
公共指纹命名空间为 `design-sha256-v1`，不直接沿用其他协议的已批准指纹。

## 检查范围

内容扫描仅是已知模式检查，不能证明所有商业信息均已识别，也不判定原始资产的权利归属。
项目已采用 Apache License 2.0。初始抽取在独立本地仓库完成；公开提交不包含来源仓库历史。
